- 시험 120분, 개인 평가, 100점. ImageNet으로 사전학습된 MobileNetV2를 불러와 사용하며, 시험 중 모델을 새로 학습하지 않습니다.
- **Teachable Machine 직접 학습, Roboflow/YOLO 훈련은 평가하지 않습니다.**

## 진행 방식
- 시험지(구글 문서)를 [파일 → 사본 만들기]로 복사해 답안지로 사용합니다. 각 문제의 따라하기 체크리스트를 따라 노트북의 실습 1~7을 순서대로 실행하고, 결과를 답안지의 답안 칸에 적습니다.
- 노트북은 5주차 워크북처럼 `____` 빈칸만 채우면 실행됩니다.
- 답안지의 각 답안 칸 옆 **취득 | 배점** 칸은 채점자가 기입합니다.

| 문제 | 노트북 실습 | 배점 |
| --- | --- | --- |
| 1. 사전학습 모델 불러오기 | 실습 1, 2 | 15 |
| 2. 직접 촬영한 사진 분류하기 | 실습 3, 4, 5 | 30 |
| 3. 결과 분석 | 실습 6 | 20 |
| 4. 조건을 바꿔 다시 실험하기 | 실습 7 | 15 |
| 5. AI 핵심 용어 (10문항) | 답안지에 바로 작성 | 20 |
| 합계 | | 100 |
