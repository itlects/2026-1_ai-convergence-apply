# 8주차 중간고사 — PDF 문서 RAG 챗봇 만들기

**실습 주제: 인공지능 RAG(검색 증강 생성) 챗봇으로 「2026 복지사업 가이드북」 PDF 질의응답하기**

- [학생용 Colab 노트북](./Week08_midterm_student.ipynb)
- [Google Colab에서 열기](https://colab.research.google.com/github/itlects/2026-1_ai-convergence-apply/blob/main/week08_midterm/Week08_midterm_student.ipynb)
- 시험 120분, 개인 평가, 100점, API 키 불필요. 7주차 워크북 1(PDF 추출·청킹·TF-IDF 검색·평가)과 워크북 2(임계값 판정·프롬프트·채팅 화면)를 변형했습니다.
- 문서: 근로복지공단 「2026 복지사업 가이드북」(28쪽). 노트북이 공단 홈페이지 → 이 저장소 `data/` 백업 순서로 내려받습니다.

## 진행 방식
- 시험지는 종이로 출력해 배부하며, 그대로 답안지로 사용합니다. 학생은 노션 실습 가이드를 보며 노트북의 실습 0~7을 순서대로 실행하고, 결과를 종이 답안지에 적습니다.
- 노트북은 7주차 워크북처럼 `____` 빈칸만 채우면 실행됩니다.
