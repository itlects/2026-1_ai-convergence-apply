# 워크북 2 — 카메라 이미지 수집·96×96 전처리·갤러리

## 완성 목표
AI Thinker ESP32-CAM의 OV2640으로 320×240 JPEG를 촬영해 microSD에 저장하고, PC로 옮겨 96×96 PNG 이미지를 만든 다음 브라우저 갤러리에서 확인합니다.

## 준비물
AI Thinker ESP32-CAM(OV2640 포함), microSD(FAT32), USB-TTL 시리얼 변환기(3.3V UART 신호), 안정적인 5V 전원, PC. **ESP32-DevKitC V4는 워크북1에서 사용하며 카메라 보드와 직접 연결할 필요가 없습니다.**

## 이론 키워드
| 키워드 | 의미 |
|---|---|
| OV2640 | ESP32-CAM에 연결된 이미지 센서 |
| JPEG | 압축 이미지 형식, 촬영 파일 저장에 적합 |
| esp_camera_init | 카메라 핀·해상도·JPEG 설정 초기화 |
| esp_camera_fb_get | 촬영된 프레임 버퍼 획득 |
| esp_camera_fb_return | 촬영 프레임 버퍼 반환(메모리 누수 방지) |
| SD_MMC.begin | microSD 마운트; true=1비트 모드 |
| canvas.drawImage | 이미지 크기 변환·중앙 정사각형 자르기 |
| toBlob | 변환된 Canvas 이미지를 PNG 파일로 만들기 |
| 라벨/클래스 | 이미지가 속한 의미 범주(예: 정상/불량) |

## ESP32-CAM 업로드 배선
| USB-TTL | ESP32-CAM | 설명 |
|---|---|---|
| TXD | U0R (RX) | 교차 연결 |
| RXD | U0T (TX) | 교차 연결 |
| GND | GND | 공통 접지 |
| 5V 안정화 전원 | 5V | 변환기 공급 용량이 부족하면 별도 5V 사용 |
| GPIO0 | GND (업로드할 때만) | 업로드 완료 후 반드시 제거 |

UART TX/RX는 3.3V 로직이어야 하며 5V TTL 신호를 직접 넣으면 안 됩니다. 외부 5V와 USB-TTL의 전원 출력을 서로 단락하거나 병렬로 연결하지 말고 접지는 공통으로 합니다.

## 실행 순서 A — 촬영 및 SD 저장
1. microSD 카드를 FAT32로 준비하고 ESP32-CAM 슬롯에 삽입합니다(전원 꺼진 상태).
2. 업로드 배선을 확인하고 Arduino IDE에서 보드 `AI Thinker ESP32-CAM`을 선택합니다.
3. [카메라 촬영 완성 코드](./02_camera_sd/camera_sd.ino)를 열어 업로드합니다.
4. GPIO0-GND 연결을 해제하고 보드 리셋 버튼을 누릅니다.
5. 시리얼 모니터 115200에서 `Ready. Send c + Enter to capture.`를 확인합니다.
6. `c`를 전송해 이미지 3장 이상을 찍습니다. microSD에서 `image_0001.jpg` 등을 PC로 복사합니다.
7. 이미지 속성에서 해상도, 바이트 수, 촬영 피사체, 조명을 기록합니다.

## 실행 순서 B — 이미지 전처리·갤러리
1. [갤러리 앱 전체 HTML](./03_gallery/gallery.html)을 PC에 다운로드한 후 Chrome 또는 Edge에서 엽니다.
2. 촬영한 JPEG 여러 장을 선택합니다. 카메라가 없으면 **시연용 이미지 3장 생성**을 클릭해 대체 데이터를 준비합니다.
3. 미리보기 이미지와 변환 결과 `96×96`을 확인합니다.
4. 각 `96×96 PNG 저장`을 클릭해 이미지 파일을 다운로드합니다.
5. 브라우저 창과 파일 속성 화면을 캡처합니다.

**전처리 주의:** 앱은 원본 가로·세로 중 짧은 변 길이로 중앙을 정사각형으로 자른 뒤 96×96으로 리사이즈합니다. 이미지가 잘리는 것이 싫다면 레터박스 패딩 방식과 결과를 비교해보세요. 갤러리는 로컬 파일을 브라우저 메모리에서 처리하며 서버 업로드를 하지 않습니다.

## 질문
1. JPEG와 PNG는 왜 파일 크기가 다른가요?
2. 320×240 이미지를 96×96으로 줄이면 총 픽셀 수가 어떻게 바뀌나요? (76,800 → 9,216)
3. 중앙 자르기(center crop)로 사라지는 정보는 무엇인가요?
4. AI 학습을 위해 클래스 간 이미지 수와 배경 조건을 어떻게 구성해야 하나요?
