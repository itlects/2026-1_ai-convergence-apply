JSONL = 한 줄에 JSON 하나
· text: 검색에 쓰는 교정 문장
· stt_raw: 추적용 원문
· source: 근거 출처(WAV)
· verified: true만 검색

같은 질문, 지식 추가 전/후 검색 1순위 근거

기존 지식 5건(문서) → 추가 후 9건(문서 5 + 음성 4). 모델은 그대로, 검색 대상만 늘었다.
질문추가 전 1순위 (점수)추가 후 1순위 (점수)

단어는 겹치지만 질문의 답이 아님		✓ 빨강 부품은 검사 후 왼쪽 상자에 보관합니다. (0.63)

균열이 보이면 어떻게 해?△ 균열이나 변형이 있는 부품은 불량으로 분류한다. (0.38)✓ 빨강 부품에 균열이 보이면 재검사 상자로 옮깁니다. (0.51)

점수 = TF-IDF 글자 조각 코사인 유사도. 점수가 높다고 정답은 아니다(첫 줄). 0.25 미만은 “근거 없음”.

모델 학습 vs 지식베이스 갱신

🧠 모델 학습 (워크북 1-3)
데이터: 학습 사진 10장 → 평균 RGB
바뀌는 것: 모델 값(빨강·파랑 중심)
효과: 새 사진의 인식 결과가 바뀜
다시 하려면: 사진을 모아 다시 계산
📚 지식베이스 갱신 (워크북 2)
데이터: 음성 → 텍스트 → JSONL 줄
바뀌는 것: 검색 대상 문서
효과: 질문의 답변 근거가 바뀜
다시 하려면: 줄 추가·삭제(모델 그대로)
공통 원칙
· 데이터 품질이 결과를 결정
· 사람 확인(Human-in-the-loop)
· 출처 기록 → 추적 가능
