# 14주차 종합 프로젝트

Windows 10/11, Python 3.10 이상, Chrome 또는 Edge. 패키지 설치 없이 로컬 Python 서버를 실행한다. 음성 인식은 브라우저 기능이며 브라우저/네트워크/마이크 권한에 따라 실패할 수 있다. 음성 인식이 지원되지 않으면 텍스트 입력으로 핵심 검색을 검사한다. 음성 합성도 사용 가능한 한국어 음성에 따라 달라진다. 외부 STT 서비스에 음성이 전달될 수 있으므로 개인정보는 말하지 않는다.

## 실행 순서
1. 모든 파일을 같은 폴더에 둔다.
2. 터미널에서 `python -m unittest -v` 실행: OK 확인.
3. 프로젝트 A: `python server.py --project campus --port 8000`
4. 브라우저에서 http://127.0.0.1:8000 접속.
5. 도서관 운영 시간 입력 → 검색 → C01 확인 → 답변 읽기 → 마이크 입력 비교.
6. 종료: Ctrl+C.
7. 프로젝트 B: `python server.py --project lab --port 8001`
8. http://127.0.0.1:8001 접속 → DHT11 온도 질문 → L01 확인.
9. 우주선 질문 → 근거 없음 확인.

## 바이브코딩 지시문 (Claude 또는 Cursor)
아래 지시문을 입력하고 생성한 코드와 제공된 검증용 코드를 비교한다.

> Windows에서 실행하는 Python 3 표준 라이브러리 웹 서버를 만들어라. 파일은 server.py, index.html, campus.json, lab.json, test_server.py로 분리한다. 브라우저에서 한국어 STT로 음성 입력을 텍스트로 변환하고 POST /ask JSON으로 전송한다. 키워드 검색으로 가장 관련 있는 지식 문서를 선택하고 답과 근거 ID를 반환한다. 근거가 없으면 모른다고 답한다. 답변은 브라우저 TTS로 읽는다. 마이크 미지원 시 텍스트 입력을 제공한다. 서버는 localhost에만 연결하고 개인 정보와 API 키를 저장하지 않는다. 단위 테스트와 HTTP 요청 테스트를 작성하고 실행 순서와 예상 결과를 단계별로 설명한다. 기존 프로젝트에 기능 하나(예: 카테고리 필터, 질문 기록, 검색 점수)를 추가할 수 있게 한다. 코드 전체를 파일별로 줄바꿈을 유지해 제시하라.

이 코드는 검색 증강 응답의 추출형 기준선이다. 생성형 LLM을 연결한 완전한 RAG는 심화 선택: 검색 문서와 질문을 모델에 제공하고 근거 밖 내용은 답하지 않도록 지시한다. LLM 없이도 STT→검색→응답→TTS 흐름을 검증할 수 있다.

## 평가 제출
팀/개인 주제, 문제 정의, 입력·처리·출력 구조, 바이브코딩 지시문과 수정 내역, 데이터 출처, 실행 캡처, 정상 질문 3개와 미등록 질문 1개의 결과표, 음성 입력/출력 결과 및 실패 대체 경로, 개선점, 소스 ZIP.
